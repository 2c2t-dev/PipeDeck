# Icons

These are [Material Symbols](https://github.com/google/material-design-icons),
rounded and filled, by Google, under the Apache License 2.0. Only the file
names were changed, to the `pd-*-symbolic` names the application asks the
icon theme for.

The full licence is in `LICENSE`.

Why bundle them rather than ask the desktop's icon theme: an icon name a
theme lacks is drawn as a broken image, and the names that do exist come
from different sets and rarely look like one another. A mixer's icons sit
side by side in a small grid, where that shows.
