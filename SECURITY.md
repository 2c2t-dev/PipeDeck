# Security

## Reporting a problem

Please report a security problem privately, through
[GitHub's private reporting](https://github.com/2c2t-dev/PipeDeck/security/advisories/new),
rather than in a public issue. You will get an answer, and credit if you
want it, once it is fixed.

## Supported versions

Fixes go into the next release; the latest release is the one supported.
